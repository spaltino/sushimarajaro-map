## 3차 보강 (2026-11-17 저녁)

1. **상하이 3곳 릴레이 동선** (`#shanghai-relay`) — 2026-11-26(목) 기준 Google Maps 실측 동선. 오전에 핵심인 **런지병원 동원 국제의료부(12:15 예약·508위안)** 를 먼저 잡고, 오후에 **동방병원 본부**(12:30~15:30 접수·25위안) → **공리병원**(~16:30·25위안·목요일 오후 비만 전문클리닉) 순으로 도는 표. 택시 4구간 82.6km, 17:00 공항 복귀. 푸난병원은 런지 협력 분원이라 전산 연동 리스크를 피해 3번째는 동방 본부를 권장.
2. **외배처방 약국 백업 3단계** — 원내 약국 품절 시 ① 진료실 요청 문장 `如果院内药房没货，请开纸质外配处方，谢谢。`(복사·큰 글씨) ② 처방전 3항목(여권 영문명·번호 / 규격 `2.4ml:20mg` / 의사 서명·병원 직인) ③ 문전 지정약국(런지 앞 `国大龙威大药房 浦建路店` 浦建路111号 24시간 · 공리 앞 `苗圃路店` 219~221号).
3. **대마도(쓰시마) 배송 루트** (`#tsushima`) — 폰타나 클리닉 공식 안내 기준. 온라인 진료 후 대마도 숙소·야마토 영업소 배송, 약값 **+2,500엔**(배송비·일영 처방전), 배송 2~3일, 방문 7일 전까지 진료 권장. 부산↔히타카츠 배편 1시간 10~30분, 영업소 냉장 보관 3일.

## 2차 폴리싱 (2026-11-16 밤)

1. **도시 배지 겹침 해소** — 전체 보기(동아시아 줌)에서 `상하이 · 항저우 · 닝보` 배지가 서로 겹치던 문제를 화면 픽셀 기준 충돌 계산으로 해결했습니다. 배지는 실제 좌표에 점으로 남고, 밀려난 만큼 **얇은 지시선**으로 이어집니다. 지도 확대·축소(`zoomend`)와 모바일 뷰포트에 맞춰 매번 다시 계산합니다. 데스크톱은 배지 아래 도시 이름, 모바일은 32px 배지만 표시합니다.
2. **계산기 손익분기 인사이트** — 결과 상단에 현재 조건(출발 공항 · 용량 · 기간) 기준으로 **가장 싼 원정지 vs 한국 대비 절약액**, 그리고 **몇 개월부터 원정이 이득인지(손익분기)** 를 한 줄 배지로 보여 줍니다. 한국이 더 싼 조건에서는 배지 색이 주황으로 바뀌고 차액을 표시합니다.
3. **FAQ 아코디언 7문항** — `<details>` 기반(자바스크립트 없이도 동작) + "모두 펼치기" 버튼. 같은 내용을 `FAQPage` 구조화 데이터(JSON-LD)로도 넣어 검색 노출을 돕습니다.
4. **공유 완성도** — `og:title · og:description · og:url · og:site_name · og:locale · og:image(1200×630)` + `twitter:card(summary_large_image)` + `canonical` + `theme-color`. 공유 미리보기 이미지는 `og-image.png`입니다.
5. **모바일 계산기 재배치** — 아이폰 사파리에서 입력 폼이 스크롤 밖으로 밀리던 문제를 고쳤습니다. 모바일에서는 **입력 폼(공항·용량·기간)이 먼저**, 바로 아래에 **핵심 결과(가장 싼 방법 + 3열 비교 카드)** 가 한 화면에 들어오도록 간격·글자·패딩을 압축했습니다. 상단 탭은 **국가 스위처 1단 + 도시 탭 가로 스크롤 2단**으로 정리해 오른쪽이 잘리지 않습니다.
