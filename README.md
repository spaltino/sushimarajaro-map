- 라이브: <https://spaltino.github.io/sushimarajaro-map/>
- 중국 단독판: <https://spaltino.github.io/malajaro-map/> (별도 저장소, 그대로 유지)

## 데이터 기준 (2026-11-16)

- **일본 클리닉 11곳**: 각 클리닉 **공식 가격표 페이지**(세금 포함)에서 1본 가격·진찰료·예약 방법·진료 시간 확인. 좌표·영업시간은 Google Maps, 도보 시간은 Google Maps 경로, 철도는 Yahoo!乗換案内(2026-11-17 10:00 출발 기준).
- **일본 제도**: 후생노동성·PMDA 자료 — 마운자로 적응증은 2형 당뇨병, 비만은 젭바운드(2024-12-27 승인, 2026-05-18 적응 추가). 자유진료는 부작용 구제제도 대상 아님.
- **중국 데이터**: 별도 저장소 `malajaro-map`의 검증된 데이터(전화 확인·후기·공식 안내)를 그대로 사용.
- **세관**: 식약처·관세청 2026-11-11 합동 발표(11-12 시행) — 기본 6병, 초과 시 용법상 3개월분, 주 1회 주사제는 **12개** 예시.
- **환율**: 100엔 = 834원, 1위안 = 200원 (2026-11-16 수출입은행 매매기준율).
- **항공권**: 2026-11-16 조회 왕복 직항 최저가대(스투비플래너·트립닷컴·KAYAK·여행비교).
